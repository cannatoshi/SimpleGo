# Reply Queue E2E Decryption: Complete Code Path
 
## Overview
 
When the **Creator** receives a message from the **Joiner** on a Reply Queue,
there are TWO crypto_box layers that must be decrypted sequentially.
 
## Two-Layer Decryption Model
 
| Layer | DH Secret | Nonce | Purpose |
|-------|-----------|-------|---------|
| Layer 1: Server→Recipient | `rcvDhSecret` | `cbNonce(msgId)` | Server-level encryption |
| Layer 2: Sender→Recipient E2E | `e2eDhSecret` (computed from `e2ePubKey`) | `cmNonce` (random, in envelope) | Per-queue E2E encryption |
 
## Step-by-Step Decryption Sequence
 
### Step 1: Server-Level Decrypt (Layer 1)
 
**Entry:** `Agent.hs:2694`
```haskell
SMP.MSG msg@SMP.RcvMessage {msgId = srvMsgId} -> do
    msg' <- decryptSMPMessage rq msg
```
 
**Function:** `Client.hs:1682-1686`
```haskell
decryptSMPMessage :: RcvQueue -> SMP.RcvMessage -> AM SMP.ClientRcvMsgBody
decryptSMPMessage rq SMP.RcvMessage {msgId, msgBody = SMP.EncRcvMsgBody body} =
  liftEither $ parse SMP.clientRcvMsgBodyP (AGENT A_MESSAGE) =<< decrypt body
  where
    decrypt = agentCbDecrypt (rcvDhSecret rq) (C.cbNonce msgId)
```
 
- **DH secret**: `rcvDhSecret` from `RcvQueue` (`Store.hs:77`)
- **Nonce**: `C.cbNonce msgId` — msgId truncated/padded to 24 bytes (`Crypto.hs:1372-1378`)
- **Output**: `ClientRcvMsgBody` with `msgBody :: ByteString`
 
### Step 2: Parse ClientMsgEnvelope (Extract E2E Public Key)
 
**Location:** `Agent.hs:2705-2707`
```haskell
clientMsg@SMP.ClientMsgEnvelope {cmHeader = SMP.PubHeader phVer e2ePubKey_} <-
    parseMessage msgBody
```
 
The `msgBody` from Layer 1 is parsed as `ClientMsgEnvelope` (`Protocol.hs:1067-1089`):
 
```haskell
data ClientMsgEnvelope = ClientMsgEnvelope
  { cmHeader  :: PubHeader,      -- plaintext header (version + optional E2E pub key)
    cmNonce   :: C.CbNonce,       -- 24-byte nonce for E2E decrypt
    cmEncBody :: ByteString       -- E2E-encrypted body
  }
 
data PubHeader = PubHeader
  { phVersion    :: VersionSMPC,
    phE2ePubDhKey :: Maybe C.PublicKeyX25519   -- Joiner's ephemeral DH public key (SPKI-encoded)
  }
```
 
The SPKI bytes visible at offset 16 after server-decrypt are the `phE2ePubDhKey` —
the joiner's ephemeral X25519 public key encoded as ASN.1 DER X.509 SubjectPublicKeyInfo
via `encodePubKey = toPubKey $ encodeASNObj . publicToX509` (`Crypto.hs:604-605`).
 
### Step 3: Compute E2E DH Secret
 
**Location:** `Agent.hs:2710-2712`
```haskell
case (e2eDhSecret, e2ePubKey_) of
    (Nothing, Just e2ePubKey) -> do
        let e2eDh = C.dh' e2ePubKey e2ePrivKey
```
 
For the first message (confirmation) on a Reply Queue:
- `e2eDhSecret` is `Nothing` (not yet established)
- `e2ePubKey_` is `Just` (joiner included ephemeral DH public in PubHeader)
- **DH calculation**: `X25519.dh(joiner_ephemeral_pub, creator_e2ePrivKey)`
 
`C.dh'` at `Crypto.hs:1262-1263`:
```haskell
dh' (PublicKeyX25519 k) (PrivateKeyX25519 pk _) = DhSecretX25519 $ X25519.dh k pk
```
 
For subsequent messages, the stored `e2eDhSecret` is reused (branch at `Agent.hs:2722`).
 
### Step 4: E2E Decrypt (Layer 2)
 
**Location:** `Agent.hs:2885-2896`
```haskell
decryptClientMessage :: C.DhSecretX25519 -> SMP.ClientMsgEnvelope -> AM (SMP.PrivHeader, AgentMsgEnvelope)
decryptClientMessage e2eDh SMP.ClientMsgEnvelope {cmNonce, cmEncBody} = do
    clientMsg <- liftEither $ agentCbDecrypt e2eDh cmNonce cmEncBody
    SMP.ClientMessage privHeader clientBody <- parseMessage clientMsg
    agentEnvelope <- parseMessage clientBody
    pure (privHeader, agentEnvelope)
```
 
The nonce is `cmNonce` from the `ClientMsgEnvelope` — a random 24-byte nonce
generated by the sender (`Client.hs:1927`). It is NOT derived from the message ID.
 
**Actual crypto operation:** `Client.hs:1950-1953` → `Crypto.hs:1302-1303` → `Crypto.hs:1326-1334`:
```haskell
sbDecryptNoPad_ secret (CbNonce nonce) packet
  | B.length packet < 16 = Left CBDecryptError
  | BA.constEq tag' tag = Right msg
  | otherwise = Left CBDecryptError
  where
    (tag', c) = B.splitAt 16 packet    -- first 16 bytes = Poly1305 auth tag
    (rs, msg) = xSalsa20 secret nonce c -- XSalsa20 decrypt
    tag = Poly1305.auth rs c            -- recompute & verify tag
```
 
This is NaCl crypto_box_open: XSalsa20-Poly1305.
 
### Step 5: Parse Decrypted Plaintext
 
After decrypt, parsed as `ClientMessage` (`Protocol.hs:1091, 1108-1110`):
```haskell
data ClientMessage = ClientMessage PrivHeader ByteString
```
 
`PrivHeader` (`Protocol.hs:1093-1106`):
```haskell
data PrivHeader
    = PHConfirmation C.APublicAuthKey   -- 'K' + sender's auth public key
    | PHEmpty                            -- '_'
```
 
For the first joiner→creator message: `PHConfirmation senderKey`.

## Sender Side (Joiner Encrypting)
 
The joiner uses `agentCbEncryptOnce` at `Client.hs:1936-1946`:
```haskell
agentCbEncryptOnce clientVersion dhRcvPubKey msg = do
    (dhSndPubKey, dhSndPrivKey) <- atomically $ C.generateKeyPair g
    let e2eDhSecret = C.dh' dhRcvPubKey dhSndPrivKey
    cmNonce <- atomically $ C.randomCbNonce g
    cmEncBody <- C.cbEncrypt e2eDhSecret cmNonce msg ...
    let cmHeader = SMP.PubHeader clientVersion (Just dhSndPubKey)
    pure $ smpEncode ClientMsgEnvelope {cmHeader, cmNonce, cmEncBody}
```
 
The joiner generates an ephemeral keypair, computes `dh'(creator_rcv_pub, joiner_ephemeral_priv)`,
puts `joiner_ephemeral_pub` in the PubHeader (the SPKI seen in hex dumps), and uses a random cmNonce.
The creator computes the same shared secret via `dh'(joiner_ephemeral_pub, creator_e2ePrivKey)` —
standard ECDH symmetry.
